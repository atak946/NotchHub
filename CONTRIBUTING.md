# Contributing

Thanks for helping improve NotchHub.

## Workflow

1. Fork the repository and create a branch from `main`.
2. Run `brew install xcodegen` and `xcodegen generate`. A `Config/Local.xcconfig` is optional.
3. Make your change. Keep files and functions small and avoid magic numbers.
4. Add or update tests (Swift Testing). The full suite must pass:
   `xcodebuild -project NotchHub.xcodeproj -scheme NotchHub test`
5. Open a pull request against `main`. Every PR needs CI to pass and a review from the maintainer before it
   is merged.

## Conventions

- **Language:** the app UI stays **Turkish**. Code, comments, logs, docs and commit messages are in English.
- **Concurrency:** Swift 6 with strict concurrency. New warnings are not accepted.
- **Generated project:** `NotchHub.xcodeproj` is generated by XcodeGen. Change `project.yml`, never the project
  file.
- **No personal data:** do not commit your own bundle id, team id, signing identity or paths. Put them in
  `Config/Local.xcconfig`, which is gitignored.
- **Commits:** use conventional commit messages (`feat:`, `fix:`, `refactor:`, `chore:`, `docs:`, `test:`).

Report security issues privately as described in [SECURITY.md](SECURITY.md), not in public issues.
